# Liriano Ortiz Rent a Car

Sitio estático listo para GitHub Pages.

## Publicar
1. Crea un repositorio nuevo en GitHub, por ejemplo `liriano-ortiz-rent-a-car`.
2. Sube `index.html` y la carpeta `assets/` a la raíz del repositorio (no subas solamente el ZIP).
3. En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
4. Espera a que GitHub publique la URL que aparece en Settings → Pages.

## Cómo funcionan las solicitudes
- El formulario abre WhatsApp al número +1 973-653-4258 con el mensaje listo para enviar. El sitio también muestra WhatsApp RD +1 829-543-6144 como contacto alternativo.
- El cliente debe pulsar Enviar en WhatsApp.
- No hay reservas confirmadas automáticamente, base de datos, disponibilidad en tiempo real ni calendario de fechas bloqueadas.
- Las fechas se seleccionan con calendarios nativos del navegador; el dueño revisa y aprueba manualmente.
- No se muestran tarifas porque aún no se han proporcionado.

## Próxima fase recomendada
Para un panel privado, calendario compartido, bloqueo de fechas y seguimiento de solicitudes, conectar un backend (por ejemplo Supabase) con autenticación y políticas de acceso. Nunca guardar claves privadas en este repositorio público.

Las imágenes promocionales proporcionadas se utilizan como recursos gráficos. Confirma que los modelos, años, características y fotografías corresponden a los vehículos reales antes de publicar.
